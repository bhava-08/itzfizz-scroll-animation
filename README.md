# Itzfizz Scroll-Driven Hero Animation

A modern scroll-driven hero section created as a web development internship assignment for Itzfizz Digital.

## Features

- Responsive hero section
- Letter-spaced headline
- Animated statistics
- GSAP entrance animations
- GSAP ScrollTrigger scroll-based animation
- Smooth visual movement
- Responsive mobile layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger

## Assignment

Created as part of the Web Development Internship application process at Itzfizz Digital.
